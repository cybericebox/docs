Платформа Cyber&nbsp;ICE&nbsp;Box проводить навчання і змагання CTF: завдання з автоматичною перевіркою, заходи з реєстрацією
і таблицею результатів, каталог завдань і панель організатора. Вона працює поверх [лабораторії](/laboratory/), яка
запускає мережі та машини завдань.

## Що вона дає

| Напрям | Що ви отримуєте |
|---|---|
| Заходи | Формат, реєстрація, завдання з каталогу, сторінки заходу і живий екран для зали. Організатор налаштовує захід сам |
| Завдання | Прості завдання перевіряються прапором. Навчальні завдання перевіряються автоматично, крок за кроком, без прапорів і таблиці результатів |
| Лабораторії | Кожне завдання з інфраструктурою отримує власну ізольовану мережу. Вхід: профіль WireGuard в один клік або окремий вузол просто в браузері |
| Участь | Особисто або командою: формат обирає організатор. У командному заході команду створюють або приєднуються до неї за кодом |
| Оцінювання | Бали можуть бути динамічними: що більше учасників розв'язало завдання, то менше воно коштує. Таблиця результатів оновлюється наживо |
| Чесна гра | Прапори перевіряються на сервері, лабораторії ізольовані одна від одної, організатор бачить кожну спробу |

## З чого вона складається

| Частина | Що це |
|---|---|
| Бекенд | Користувачі, заходи, завдання, каталог. Керує лабораторією через один API |
| ID | Вхід, реєстрація, налаштування облікового запису |
| Панель платформи | Адміністрування користувачів, заходів і налаштувань |
| Каталог завдань | Створення, редагування і перевірка завдань |
| Сайт заходу | Публічні сторінки, кабінет учасника, панель заходу |

Код відкритий: платформу можна розгорнути на власних серверах.
