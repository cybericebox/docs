The Cyber&nbsp;ICE&nbsp;Box platform runs training and CTF competitions: auto-checked tasks, events with registration and a
scoreboard, a task catalog and an organizer's panel. It runs on top of the [laboratory](/en/laboratory/), which
runs the networks and machines of the tasks.

## What it gives you

| Area | What you get |
|---|---|
| Events | Format, registration, tasks from the catalog, event pages and a live screen for the venue. The organizer sets the event up themselves |
| Tasks | Simple tasks are verified with a flag. Training tasks are checked automatically, step by step, with no flags and no scoreboard |
| Labs | Every task with infrastructure gets its own isolated network. The way in: a one-click WireGuard profile, or a single host right in the browser |
| Participation | Solo or in a team: the organizer picks the format. In a team event you create a team or join one with a code |
| Scoring | Points can be dynamic: the more participants solve a task, the fewer points it is worth. The scoreboard updates live |
| Fair play | Flags are checked on the server, labs are isolated from each other, and the organizer sees every attempt |

## What it consists of

| Part | What it is |
|---|---|
| Backend | Users, events, tasks, the catalog. Drives the laboratory through one API |
| ID | Sign-in, registration and account settings |
| Platform panel | Administration of users, events and settings |
| Task catalog | Creating, editing and testing tasks |
| Event site | Public pages, the participant area, the event panel |

The code is open: you can run the platform on your own servers.
